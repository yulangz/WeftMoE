**FC1 组合优化，2026-09-17，1620 MHz**

相对已包含 saved-X 保存与缓冲区复用的基线，八种训练配置的 wall 中位数变化为 -0.80% 到 +3.41%，GPU 中位数变化为 -0.82% 到 +3.49%；正数表示改善。尚未应用到工作区。

三个修改保留 GEMM 的 K 归约顺序、BF16 检查点和后续乘法/舍入顺序：

- FC1 的 N128 gate/up 权重按 stage 相邻存放，合并成原生 N256 WGMMA。其他 tile 宽度保留原路径；相应指令统计公式也已更新。
- A 必须先舍入到 BF16，因此只有 65536 种输入位型。每个 pool slot 一次性生成原公式的 FP32 `a * sigmoid(a)` 表；Forward 查表后仍按原顺序乘 B 和 gate。这是完整位型映射，不是近似激活。
- 完整 FC1 tile 的 S/A/B 用 TMA 写回。每个共享内存写入线程先执行 proxy fence，再通过 math barrier 汇合；issuer 完整等待 TMA 写入，然后才发布 FC1 完成。expert 尾部保留带边界检查的写入。

LUT 本体每槽 256 KiB，加上布局对齐，本次每卡单槽 pool 增加 262264 字节。初始化在 pool 创建时执行，并在向任意 execution stream 发布资源池前完成一次 stream 等待；稳态 Forward 不增加初始化或分配。调用者拥有的 X/A/B 生命周期不变。

两节点各八卡固定 1620 MHz，训练八种配置每项两轮，每轮 10 次预热、100 次正式样本；第二轮反转 case 和实现顺序，共 3200 个训练样本。推理另测两个 EP8 case，每轮 60 个样本，共 480 个。实际 native retained-state 标志分别全部为 1/0，全输出重复校验次数全部为零。编译、正确性检查和计时分开；每样本取最慢 rank，wall 包含 Notify、当次 tensor 分配与输入克隆。所有离群值保留。

验证：

- 两模型各 160 份 Forward/Backward 张量与既有参考逐字节一致，包括 saved X/A/B、dX、dgate、dW1、dW2。
- EP8×258 与 EP16×129 重分片、129/258/8K/64K 共同前缀逐字节一致；八种配置每 rank 20 次全输出重复检查通过。
- 八种配置各三次全梯度重复检查及额外 CPU 全量重复比较通过，四种梯度哈希与冻结 saved-X 基线一致。
- 两模型 graph、跨 stream 消费、偏斜路由、空 rank、池扩容和旧保留状态复用通过；EP1/EP2 元数据、取消/deadline，以及 EP8/EP16 rank 0 故障传播通过。
- Qwen 单卡 E8/top-k8、129 tokens 的 Compute Sanitizer memcheck 设备错误为零。禁用 API 错误报告以排除已处理的 NCCL 架构探测调用；不代表所有 CUDA API 都无错误。
- 精确 LUT 独立探针覆盖全部 65536 种 BF16 A 位型，与 16 种 B、16 种 gate 组合，共 16777216 个用例，FP32 factor、中间结果和 BF16 输出位型均相同，包括零、次正规数、无穷和 NaN。
- 两模型各两个主 unified Backward kernel 的 SASS 指令文本和编码与基线一致；未更改反向算法。本轮不宣称反向性能提升。
- 纯 GEMM 诊断修复了 marker 提取、checkpoint 排除和 barrier 映射，并支持 packed/unpacked producer。Qwen 基线和候选的 FC1、共享 B 的 FC1、FC2 以及 N64/N128 的 WGMMA wait-group=1 路径，共十项通过 cuBLAS 全输出比较和重复检查。
- 17 项 launcher 测试全部通过。Host autotune 51 项测试中 46 项通过，另外 3 fail/2 error 在干净 HEAD 上同样复现，涉及已有参数面与默认配置漂移。
