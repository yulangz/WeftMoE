# FC1 布局控制实验（2026-09-17）

生产源码保持已验证的 saved-X/fullreuse。候选均在独立快照中构建。固定两节点 SM 1620 MHz，GPU 实验串行，编译与计时分离；每组 10 次预热、100 次计时，正序与反序各一轮。训练模式保留反向状态，计时期间没有重复性检查。

三个控制分别为：仅扩容内存池（padding）；扩容并初始化未使用的 SiLU 表（poolonly）；仅增加两个未使用的 tensor-map 参数（paramonly）。三者各通过 160 份前后向参考逐字节对比。padding、poolonly 的全部六个主前后向内核与基线 128 位机器码完全一致，包括每条指令的控制位。paramonly 的前向指令数、操作码、寄存器、控制位不变，只有参数读取和地址计算立即数增加 256；两个反向主内核完全一致。

注意：coldtail 正序基线的 Wall P50 为约 37.01 ms，而前一组基线约 35.02/35.18 ms。rank 15 的 Dispatch 中位数从约 14.14 ms 升到 18.12 ms，其他 rank 的 Dispatch 接近原水平；随后原组合版本恢复到约 35.08 ms。该基线进程的异常完整保留，不能将相对它的表面加速解释为候选收益。远端 GPU 7 在该运行窗口 SM 采样均为 1620 MHz，显存空闲 2201 MHz、活跃主要 3201 MHz，没有非 idle throttle reason；根因未确定。逐 rank 数据及窗口监控在 baseline_anomaly.json。

coldtail 监控中另有一次远端 GPU 0 的 NVML SM 时钟返回 0 MHz（22:06:53.050 UTC，约 100.97 W，反序基线运行窗口）。API 返回成功；不推断原因、不排除该读数。其余 SM 采样均为 1620 MHz；所有监控样本完整保留。

coldtail 另通过 160 份前后向参考逐字节对比。相对原组合版本，四个前向内核只有地址立即数变化；指令数量和全部控制位一致。两个反向内核与基线 128 位机器码一致。

新布局相对原组合版本的两轮 Wall P50 分别改善约 0.085% 和 0.056%；反序轮次仍比同轮基线慢约 0.151%。收益幅度不足以解决原先的跨节点回退，当前不采用。

结论：布局控制存在运行间波动；不能仅凭亚百分比差异认定参数布局或内存池扩容是退步原因。coldtail 候选仅把组合版本新增的 LUT 偏移与两个 tensor map 移到参数末尾，原有字段位置和全部算术不变；是否采用仍取决于独立正确性、重复计时及完整模型/拓扑回归。
