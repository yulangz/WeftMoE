# N256 与 BF16 倒数修正：完整生产布局验证（2026-09-17）

候选仅改动前向计算和 WGMMA 审计计数两个文件；无额外查表、内存池或参数布局变动。基线为已采用的 saved-X/缓冲区复用版本。数值与稳定性验证通过，但 Flash 和 Qwen EP16/64K 在双顺序对照中回退，候选不采用。

频率审计限制：Flash 64K 反向进程出现功耗降频，因此连续反向数据仅作诊断，不能作为严格 1620 MHz 证据。前向有两次 NVML 返回 0 MHz，另有三次进程窗口记录 CPU 限流；具体范围与原始数据见下文。

数值约束：K 累加顺序和 BF16 检查点不变。前向 SiLU 使用一次显式 FMA 倒数修正，异常与极小倒数范围保留原始除法。该因子在当前 SM90a / CUDA 12.9 的 16 张 GPU 上通过全部 BF16 A 编码及 16,777,216 组 A/B/gate 组合的逐位检查，详见[倒数实验](fc1_reciprocal_20260917.md)。

完整最小版本通过：320 份前后向金标准文件逐字节比较；两模型 Graph、偏斜路由、空专家、跨 stream 及旧反向状态复用；129/258 小批次与跨 EP 对照、129/8K/64K 前缀逐位对照；8 个模型/EP/批次组合各 20 次全输出重复检查；8 组各 3 次全梯度重复和四项梯度哈希对照；元数据生命周期与故障退出；compute-sanitizer 零内存错误。两模型各两个反向主核与基线的完整 128 位机器码一致。

所有编译和正确性 GPU 作业在正式计时前结束，GPU 作业串行。两节点 SM 设置为 1620 MHz，逐轮记录各 rank 阶段样本；计时关闭重复检查。训练前向每次 10 轮预热、100 轮计时；反向 10+30；推理 10+60。实现顺序与案例顺序在第二轮均反转，原始样本全部保留。

频率限制：反向进程中的 Flash 64K 窗口出现 1455–1605 MHz 和 NVML 软件功耗限频位 4。旧基准未输出逐轮绝对时间戳，无法精确区分准备与计时窗口。因此这 960 个连续反向样本保留为诊断，不能作为严格 1620 MHz 的证据。另有两次前向 NVML 查询返回 0 MHz；原始返回值保留，不推断其原因。

六条计数变化均来自三次前向进程窗口的本地 CPU 限流（每次各有 nr_throttled 和 throttled_time 两条），不是 NIC 错误；已采集的 NIC 错误/拥塞计数无增量。涉及 Qwen EP16/8K 的第一轮候选、第二轮基线，以及 Flash EP16/64K 第一轮基线。这限制了这些进程耗时的精确归因。

Qwen EP16/8K 第一轮基线包含 97.6104 ms 与 57.1381 ms 的 wall 长尾。最大样本各 rank 的 Forward 约 96.96–96.97 ms，Return 约 95.75–95.81 ms；采集的 NIC 错误/拥塞和 CPU 限流计数没有增加，原因尚未确定。保留全部样本，不能将基线长尾导致的均值差异当作候选修复了停顿。

候选与基线的逐 rank device pool 字节数完全相同；WGMMA 审计计数已按打包后的投影数更新，并在 EP8 训练与推理记录中核对；EP16 汇总未导出这一计数字段，不据此声称完成 EP16 运行时计数对照。
